> **Единая точка управления в Telegram (`/hub`): установка бесплатных и лицензионных плагинов, сохранение ключей, контроль версий и фоновые уведомления об обновлениях.**

---

## ✨ Основные возможности

- **🧩 Каталог плагинов** — просмотр доступных плагинов, их статусов (`Установлен`, `Ожидает перезапуск`, `Есть обновление`) и установка в один клик.
- **🔑 Лицензии и ключи** — сохранение ключей через **«Добавить ключ»** и просмотр сохранённых ключей в разделе **«Ключи»**.
- **🔔 Автопроверка обновлений** — фоновая проверка версий самого Hub и установленных плагинов каждые `30 минут` с переключением уведомлений кнопкой **«Уведомления включены / выключены»**.
- **🛡 Безопасная загрузка** — проверка расширений (`.py`, `.pyd`, `.so`), валидация SHA-256 и синтаксиса Python, атомарная запись и архивация старых дублей.
- **🔄 Самообновление Hub** — загрузка новой версии в `W1bbexHub.py` и автоматический показ пост-рестартного баннера после перезапуска Cardinal.

---

## 📥 Установка

1. Скачайте собранный файл [**W1bbexHub.py**](../../W1bbexHub.py?raw=1).
2. Поместите его в папку `plugins/` FunPay Cardinal.
3. Перезапустите Cardinal (`/restart`).
4. Отправьте команду `/hub` в управляющем Telegram-боте.

## Интерфейс и обновления 0.5.8

- Перед загрузкой обновления Hub открывает экран с версиями и описанием изменений; само скачивание требует отдельного подтверждения. Описание текущего релиза задаётся в `RELEASE_NOTES` файла `src/runtime.py` и включается в сборку.

- Обновления Hub и установленных плагинов проверяются автоматически по выбранному интервалу: по умолчанию 30 минут. В настройках можно выбрать 30 минут, 1, 6 или 24 часа, задать от 5 до 10 080 минут либо отключить автоматическую проверку. Ручная проверка работает независимо от уведомлений и автопроверки. При включённых уведомлениях о версии Hub приходит отдельное сообщение.
- Каждая версия уведомляется один раз; «Напомнить завтра» откладывает повтор на сутки. Ошибка доставки не помечает сообщение отправленным. Установка и перезапуск запускаются пользователем.
- Описание плагина сохраняет форматирование и custom emoji из админки; состояние показано в заголовке.
- Hub проверяет обновления старых ручных установок с подтверждёнными UUID, автором и версией. При единственном авторизованном пользователе первое уведомление может прийти сразу после запуска без открытия `/hub`; общий выключатель уведомлений учитывается.
- Главная показывает ОС и Python, количество установленных и работающих плагинов, обновления и ожидающие перезапуск изменения.
- «Мои плагины» содержит установленные плагины, каталог — доступные для установки; каждый плагин открывается кнопкой с названием. Списки разбиты на страницы.
- Данные каталога и версии Hub кешируются на три минуты и обновляются в фоне; пользователь может сразу работать с предыдущими данными.
- Диагностика версий и файлов вынесена из основной карточки. ОС, Python и переключатель уведомлений видны на главной; подробное окружение также доступно в настройках.
- При ошибке сети установленными через Hub плагинами можно продолжать управлять. Ошибка загрузки отличается от пустого каталога.
- «Ключ сохранён» означает только локальное сохранение. Срок, действительность и привязка проверяются сервером при установке; ключи в ответах скрыты маской.
- Адаптивные иконки используют общий реестр. Если бот не может отправлять custom emoji, Hub повторяет запрос без иконок, сохраняя цвета кнопок. Для отправки custom emoji требуется право бота (Premium владельца либо купленное имя на Fragment); Premium получателя не требуется.

## 📁 Структура модуля

```text
plugins/w1bbex-hub/
├── build.py                         # Сборка единого W1bbexHub.py в корень репозитория
├── README.md                        # Документация плагина
├── src/
│   ├── __init__.py
│   ├── runtime.py                   # Метаданные, пути, блокировки, константы API и логирования
│   ├── storage.py                   # Атомарное хранилище настроек, лицензий и очереди очистки
│   ├── core.py                      # Версионирование (semver), метаданные плагинов и диагностика состояния
│   ├── hub_api.py                   # HTTP-клиент API каталога/триалов, идентификаторы и агрегация состояний
│   ├── installer.py                 # Скачивание, проверка SHA-256, лоадеры, архивация дублей и самообновление Hub
│   ├── manual_updates.py            # Безопасное обнаружение ручных установок
│   ├── hub_updates.py               # Фоновые уведомления о версиях самого менеджера
│   ├── catalog.py                   # Статус каталога, кэш и локальный список при сбое
│   ├── release_notes.py             # Получение списка изменений релиза Hub
│   ├── menu_background.py           # Фоновое обновление открытых экранов Hub
│   ├── navigation.py                # Навигация, страницы каталога и настройки
│   ├── transport.py                 # Telegram-транспорт, авторизация и совместимость иконок
│   ├── hub_actions.py               # Обработчики активации ключей, установки, удаления и перезапуска
│   ├── lifecycle.py                 # Планировщик обновлений, пост-рестартные отчёты и хуки жизненного цикла
│   ├── handlers.py                  # Композиция HubController, регистрация маршрутов и pre_init точка входа
│   ├── plugin.py                    # Точка входа для FunPay Cardinal (PRE_INIT, POST_INIT, DELETE)
│   └── ui/
│       ├── __init__.py              # Публичный интерфейс экранов и утилит разметки
│       ├── kit.py                   # CardBuilder, KeyboardBuilder, HTML-экранирование
│       ├── formatters.py            # Бейджи статусов, форматирование версий и команд
│       ├── icons.py                 # Реестр адаптивных иконок
│       ├── outcomes.py              # Результаты операций, ключи и уведомления
│       └── screens.py               # Сводка, каталог, карточка, настройки и диагностика
└── tests/                           # 141 тест (core, storage, UI, устойчивость и сборка бандла)
```
