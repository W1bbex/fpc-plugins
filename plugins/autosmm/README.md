# AutoSMM для FunPay Cardinal

AutoSMM обрабатывает SMM-заказы: запрашивает данные покупателя, отправляет заказ в подключённую панель и отслеживает выполнение.

## Установка через W1bbex Hub

1. Скачайте [W1bbexHub.py](../../W1bbexHub.py?raw=1).
2. Поместите файл в папку `plugins/` FunPay Cardinal и перезапустите Cardinal.
3. В управляющем Telegram-боте отправьте `/hub` и откройте каталог плагинов.
4. Выберите **AutoSMM** и нажмите **«Установить»** (плагин бесплатный, ключ Hub не нужен). При обновлении через Hub старые дубли `AutoSMM` от `@w1bbex` перемещаются в `plugins/w1bbex/archive/`.
5. Перезапустите Cardinal (`/restart`). Для управления плагином используйте `/autosmm`.

## Сборка из исходников

1. Скачайте репозиторий через **Code → Download ZIP** на GitHub и распакуйте архив, либо клонируйте репозиторий.
2. Откройте терминал в папке `plugins/autosmm` распакованного репозитория.
3. Выполните на Windows `py -3 build.py`, на Linux или macOS `python3 build.py`.
4. Скопируйте созданный в этой папке `AutoSMM.py` в папку `plugins/` FunPay Cardinal.
5. Перезапустите Cardinal и откройте `/autosmm` в управляющем Telegram-боте.

Для работы плагина нужны зависимости Cardinal и дополнительные пакеты из `requirements.txt`. Не загружайте одновременно несколько версий AutoSMM.

## Исходники

`src/` содержит модули плагина (`runtime.py`, `plugin.py`, `storage/`, `core/`, `services/`, `tg/`), `build.py` собирает установочный однофайловый `AutoSMM.py`, `tests/` содержит модульные проверки. Версия — 1.0.1.
